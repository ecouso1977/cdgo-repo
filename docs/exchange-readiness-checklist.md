# Exchange And Marketplace Readiness Checklist

Centralized exchanges, DEX frontends, token aggregators, and analytics sites all ask for overlapping but different artifacts. Prepare these before any submission.

## Technical package

1. Verified contract source code
2. Mainnet contract address
3. Token name, symbol, decimals, total supply, circulating supply
4. Deployment transaction hash
5. Ownership and admin model description
6. Audit report and issue-remediation notes
7. Liquidity plan and supported trading pairs

## Project package

1. Official website and docs
2. Whitepaper or token design memo
3. Team and company information
4. Terms of use and privacy policy
5. Token allocation and vesting schedule
6. Treasury wallet disclosures
7. Social accounts and support contact

## Compliance package

1. Legal opinion for the target jurisdictions
2. Entity registration details
3. KYC/AML program summary if distributing through a sale
4. Restricted-jurisdiction policy
5. Market-abuse and insider-trading controls

## Marketplace sequence

1. Testnet launch and internal review
2. Audit completion
3. Mainnet deployment
4. Liquidity bootstrapping
5. Submit metadata to wallets and explorers
6. Submit to token aggregators and analytics sites
7. Apply to exchanges that accept the legal profile of the token

Do not skip the legal classification step for a US fundraising token. That is the gating item.
